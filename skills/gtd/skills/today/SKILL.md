# 오늘

집중을 고르자고 했으면("지금 뭐 하지", "포커스 정하자") 바로 "오늘 집중 고르기"를 합니다. 그 밖에는 "첫 화면"부터 합니다.

## 첫 화면

1. [gtd:scan](../scan/SKILL.md) 의 "끝난 일 정리"로 열린 항목의 실제 상태부터 맞춥니다.
2. 아래 순서로 보여 줍니다. 위에 있을수록 놓치면 안 되는 것입니다.
   1. `nod today`: 오늘 일정, 지난 것, 오늘 예정·마감, 오늘 집중.
   2. 지난 집중(`nod todo --json` 에서 `focus` 가 오늘 전인 열린 할 일). 항목마다 오늘도 집중할지(`--focus today`) 내릴지(`--focus ''`) 묻습니다.
   3. 열린 결정(`nod todo` 맨 위의 `decide`). 답은 nod 스킬대로 워커에게 전합니다.
   4. `nod todo check`: 받은 일함 건수와 가장 오래된 날, 다음 행동이 없는 프로젝트, 오래된 대기, 마지막 주간 리뷰.
3. 아래에서 처음 맞는 단계 하나를 골라, 이유 한 줄과 함께 알리고 이어 갑니다. 사용자가 다른 단계를 말하면 그쪽으로 갑니다.
   1. 받은 일함에 하루 넘게 묵은 항목이 있음: [gtd:clarify](../clarify/SKILL.md)
   2. 17시 전이고 오늘 집중이 없음: 아래 "오늘 집중 고르기"
   3. 17시 뒤: [gtd:tomorrow](../tomorrow/SKILL.md)
   4. 마지막 주간 리뷰가 7일을 넘음: [gtd:review](../review/SKILL.md)
   5. 어느 것도 아님: 무엇을 할지 묻습니다.

끝: 첫 화면을 보여 줬고, 고른 단계로 넘어갔거나 무엇을 할지 물었습니다.

## 오늘 집중 고르기

오늘 집중은 사용자가 고릅니다. 이 세션은 순위를 매긴 후보 목록을 만들고, 고른 것만 표시합니다.

1. 지난 집중이 남아 있으면 항목마다 오늘도 집중할지 내릴지 먼저 묻고 반영합니다. 첫 화면에서 물었으면 건너뜁니다.
2. 후보는 `nod todo next --json` 과 열린 결정입니다. 받은 일함에 정리 안 된 것이 많으면 후보로 함께 보되, 고른 항목은 표시하면서 다음 행동으로 정리합니다(제목을 동작으로, 상태 `next`).
3. 아래 순서로 순위를 매깁니다.
   1. 남이 기다리는 일: 회신·결정·리뷰를 기다리는 사람이 있거나, 늦으면 다른 사람·시스템이 깨지는 일. 열린 결정은 워커가 기다리니 여기입니다.
   2. 진짜 마감이 가까운 일. 마감이 지난 일은 맨 위에 둡니다. `nod today` 의 overdue·due 를 봅니다.
   3. 다른 일들의 선행 조건.
   4. 그 밖의 다음 행동.
   - nod 작업에 맡길 수 있는 일은 집중 후보가 아니라 "맡기기"로 따로 적습니다.
4. 대여섯 개를 표로 보여 줍니다: 순위, 할 일, 이유 한 줄, 걸리는 시간 짐작.
5. 사용자가 고른 것(세 개까지, 웹 화면의 Focus 도 세 개까지 받습니다)만 `nod todo set t<번호> --focus today` 로 표시합니다.
6. 지금 있는 곳·남은 시간·에너지를 알면 그에 맞지 않는 후보는 뒤로 미룹니다.

끝: 사용자가 고른 할 일에만 오늘 집중이 표시됐고, `nod today` 의 focus 에 나옵니다.
