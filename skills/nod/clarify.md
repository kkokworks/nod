# 받은 일함 비우기

1. `nod todo inbox --json` 으로 받은 일함을 받습니다. 받아 적은 순서(오래된 것부터)입니다.
2. 항목마다 [todos.md](todos.md) 의 "명료화"로 제안을 만듭니다. 메모에 `제안:` 줄이 있으면(사람 없이 모은 항목) 그것을 출발점으로 씁니다.
3. 표로 보여 줍니다: 번호(`t<번호>`), 원래 제목, 제안, 고친 제목, 상황·날짜·프로젝트.
4. 사용자의 확인을 받습니다. "다 좋아", "t3 은 버려", "t5 는 다음 주부터" 같은 답을 그대로 반영합니다. 확인 전에는 아무것도 바꾸지 않습니다.
5. 확인받은 대로 `nod todo set t<번호> --status … --title … --project … --context … --due … --start …` 로 반영합니다. 한 항목의 칸은 한 명령에 모아 바꿉니다. 버림은 `nod todo drop`, 지금 하기로 한 2분짜리는 끝난 뒤 `nod todo done` 입니다.
6. nod 작업에 맡기기로 확인한 항목은 [delegate.md](delegate.md) 대로 `nod add --todo t<번호>` 합니다.

끝: `nod todo inbox` 가 비었고, 지금 하기로 정한 것을 목록으로 보여 줬습니다.
